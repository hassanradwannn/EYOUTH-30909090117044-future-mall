# Future Mall Portfolio Project

**Project ID: EYOUTH-30909090117044**

This beginner-friendly portfolio contains three Future Mall parts:

- `EYOUTH-30909090117044_cashier.py` — a Python cashier using two parallel lists. Enter product numbers and enter `0` to finish. A 10% discount is calculated only when the total is more than AED 500.
- `EYOUTH-30909090117044_future_mall.html` — a one-page mall website. It has one `h1`, one paragraph, and exactly five shops. CSS is in the page `head` and it reuses `future_mall_logo.svg`.
- `EYOUTH-30909090117044_garage.py` — ESP32 MicroPython smart-garage code. The count stays from 0 to 15.
- `EYOUTH-30909090117044_wokwi/` — open this ID-labelled folder as a Wokwi project. Its standard Wokwi filenames, `main.py` and `diagram.json`, use the same pins as the garage code and identify the project ID in their contents.
- `EYOUTH-30909090117044_system_diagram.md` — Mermaid system diagram.

## Wokwi wiring and behavior

| Part | ESP32 pin | Behavior |
|---|---:|---|
| Entry button | GPIO 12 | Adds one car, unless the garage is full |
| Exit button | GPIO 13 | Removes one car, unless the garage is empty |
| Green LED | GPIO 25 | On while spaces are available |
| Red LED | GPIO 26 | On when 15 cars are inside |
| Yellow LED | GPIO 27 | Blinks when a car enters |
| Blue LED | GPIO 14 | Blinks when a car exits |

The buttons connect from their GPIO pin to GND. The code uses `Pin.PULL_UP`, therefore a pressed button reads `0`.
